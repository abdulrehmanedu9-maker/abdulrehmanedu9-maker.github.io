Projects

Real Time Device to Device Wireless Communication System

ESP8266, Arduino C++, ESP-NOW, PHP, MySQL, scikit-learn, TinyML

A multi-phase obstacle detection system built on two ESP8266 boards. It combines ultrasonic and PIR sensor fusion with ESP-NOW communication, and a PHP and MySQL backend with a dashboard and Isolation Forest anomaly detection. Alerts are graded by a rule based severity classifier, and a Decision Tree trained in scikit-learn runs on the ESP8266 through micromlgen, so alerts work on the device without Wi-Fi or a server.
