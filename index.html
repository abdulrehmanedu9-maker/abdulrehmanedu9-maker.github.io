Project 1 Real-Time Device-to-Device Wireless Communication SystemESP8266, ESP-NOW, PHP, MySQL, scikit-learn, TinyML

A router-free, internet-free obstacle detection system on two ESP8266 boards, developed in four phases.

Phase 1. Ultrasonic and PIR sensor fusion with a confirmation window and cooldown, sent over ESP-NOW.

Phase 2. PHP and MySQL backend with a dashboard, charts and Isolation Forest anomaly detection.

Phase 3. Distance-based severity zones and a timing pattern check combined into a final status.

Phase 4. Dual mode: a server decision matrix or a Decision Tree running on the ESP8266.

A confirmed detection reaches the dashboard in about one second. The on-device Decision Tree reached 90.85 percent accuracy on a synthetic test set.
